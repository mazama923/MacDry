Controlled CPU, memory & graphics test

Run up to 14 minutes of CPU work on at most two workers, a fixed 256 MiB memory pattern sample and a short WebGL workload. Total runtime is capped at 15 minutes. MacDry makes no intentional file writes; macOS may compress or page memory. It stops if you leave this page, a safety snapshot becomes abnormal or unavailable, the graphics context is lost, the time limit is reached, or you stop it. If thermal monitoring is unavailable, the checklist requires manual confirmation and you must watch for heat or macOS warnings.

Preflight and periodic checks read macOS memory-pressure and thermal-warning signals. They do not read temperatures, and the memory-pressure interface may vary by macOS version. An unavailable thermal signal is not a normal reading; the test can continue only after manual confirmation that the Mac is cool.

No workload starts until the preflight succeeds and you confirm the checklist.

Limits: 256 MiB is only a sample, not all RAM; macOS can still swap. The CPU calculation is not stress-ng and cannot reliably measure throttling. WebGL may use software rendering. No result certifies hardware health.
